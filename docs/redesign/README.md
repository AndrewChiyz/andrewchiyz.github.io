# 设计与资料核对

新版为原生静态站点，已移除 Jekyll、Sass、Ruby 构建依赖。旧版完整源码保存在 legacy-v1 分支及 legacy-2026-10-24 标签。2026-10-24 起直接迁移 Mengke Li 公开主页的 MIT 主题样式和布局；来源详见根目录 THIRD_PARTY_NOTICES.md。

## 设计

- 英文采用本地 Source Sans 3，中文采用本地 Noto Sans SC 子集（SIL OFL）；系统字体作为回退。字体声明及标题、正文排印在 `assets/css/typography.css`。新增中文字符后，可运行 `node scripts/update-fonts.mjs` 更新字形子集。
- 采用参考站实际的蓝色顶栏、作者侧栏、圆角正文容器、标题横线、简介框与论文卡片。两份上游 CSS 原样保留，本地加载字体资源；功能差异只在集成样式中处理。
- 首页展示简介、少量动态、代表作和学术服务；完整内容在独立页面。
- 首页“关于我”由 `scripts/redesign/about.mjs` 渲染为一个段落，选择性加粗研究方向与成果，紧接带 📢 图标的招募提示及 Join Us 链接；完整履历和招生要求保留在对应分页。
- 中英文首页、栏目和论文/课程详情外框一一对应；英文论文题名及摘要保留原文，中文详情标明“英文原文”。
- 响应式菜单、搜索、分类、引用复制、键盘焦点和减弱动画偏好。
