# 学术主页新版维护

## 分支与发布

- `master`：现有版本，开发阶段不修改、不推送。
- `legacy-v1` 与 `legacy-2026-10-24` 标签：旧版源码快照，指向 `e80f9f9`。目前只在本地；需要推送才有远程备份。
- `redesign`：新版开发分支，修改在这里进行。
- 不修改 GitHub Pages、域名、发布来源或 GitHub Actions 配置。
- 新版保存到本地 redesign 分支的提交；未推送、未上线。上线前先核对现有 Pages 来源；新版合入原发布分支后，沿用原有部署方式。
- 恢复旧版时，从旧标签恢复文件并形成普通提交，避免强推和重写历史。

## 本地维护与预览

需要 Node.js 18+，页面生成不需要 npm install。

```sh
npm run build:site
npm run check:site
npm run preview:site
```

预览地址 `http://127.0.0.1:4173`。此轻量预览只展示新版完整生成的页面；旧论文/课程详情需要 Jekyll 构建，轻量预览中会明确显示未渲染提示。修改源文件后重新执行 build，刷新页面。

GitHub 保持原 Jekyll 构建方式。完整 HTML 输出有 `layout: null`，不依赖线上运行 Node；修改后需把生成的 `_pages` 文件一起提交。

- `_data/scholar.json`：论文、动态、教学信息、教育经历及工作经历。
- `scripts/redesign/build.mjs`：双语正文、共享页面模板和生成逻辑。
- `assets/css/scholar.css`：布局、Arial 字体栈、手机样式。
- `assets/js/scholar.js`：导航菜单、论文筛选和引用复制。
- `_pages/`：生成结果，不直接编辑本次生成的文件。
- `_layouts/scholar-detail.html`：生成的旧论文/课程详情页布局。
- `_publications/`、`_teaching/`、`_talks/`：原详情内容，继续保留。
- `original-content.json`：重做前的简介、CV、完整招生正文，避免摘要迁移丢失原材料。整个 docs 目录不会发布。
- `migrate.mjs`：仅首次迁移使用，会拒绝覆盖已有数据。

## 双语与路径

英文首页 `/`，中文首页 `/zh/`；栏目同名，如 `/publications/` 对应 `/zh/publications/`。语言按钮保留当前栏目。

论文题名、作者和引用保留原文。已有论文和课程详情暂保留英文，不宣称这些旧详情已有双语翻译；中英文栏目页均可访问它们。

旧招生 `/markdown/`、`/md/`、`/markdown.html` 跳至 `/zh/joining/`；`/about/`、`/about.html`、`/resume` 保留兼容入口。原论文、课程和附件地址不变。

## 发布前需要本人核对

1. 当前职称、单位、简介及研究方向；目前依据旧站，未推断新职位。
2. 补充 2025–2026 年动态和论文；目前只迁移已有四篇论文及 2023–2024 年动态。
3. CFNet 文件日期为 2024 年，引用写 PRCV 2023；新版按引用显示 2023 年，原详情未改。
4. TMM 论文正式发表信息与 arXiv 引用应核对。
5. 代表作目前从已有论文中暂选三篇，可以用 selected 调整。
6. 头像暂沿用旧站照片；可提供更适合学术主页的照片。
7. 招生页为原文整理和英文译写；原文全部保存在存档中，请确认措辞和当前招生安排。
8. 团队成员、荣誉、论文配图尚无确认资料，不生成虚构内容。

## 验证范围

check:site 检查本地页面路径、双语链接、静态资源、旧详情目标、重复固定链接、元信息与生成稳定性。完整 Jekyll 构建及浏览器视觉验证需在具备 Ruby/Jekyll 和浏览器的环境完成；本地轻量预览不替代该检查。
