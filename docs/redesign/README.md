# 设计与资料核对

新版为原生静态站点，已移除 Jekyll 配置、主题、Sass、Ruby 和旧模板依赖。旧版完整源码保存在 legacy-v1 分支及 legacy-2026-10-24 标签。

## 设计

- Arial / Helvetica Neue 字体栈，中文使用系统字体。
- 白底、深灰正文、蓝色链接，顶部导航与个人侧栏。
- 首页展示简介、少量动态、代表作和学术服务；完整内容在独立页面。
- 中英文首页、栏目和论文/课程详情外框一一对应；英文论文题名及摘要保留原文，中文详情标明“英文原文”。
- 响应式菜单、搜索、分类、引用复制、键盘焦点和减弱动画偏好。

## 需要核对或补充

1. 当前职称、单位、研究方向；目前依据旧站。
2. 2025–2026 年动态及论文；目前只有旧站四篇论文和七条动态。
3. CFNet 源文件日期写 2024，引用写 PRCV 2023；列表按引用显示 2023。
4. TMM 论文正式发表信息及 arXiv 引用。
5. 三篇暂选代表作，可在数据中调整 selected。
6. 学术照片、论文配图、团队成员与荣誉资料。
7. 招生页为原招生说明整理及英文译写，请核对当前安排。

`original-content.json` 保留旧简介、CV 与完整招生原文，只作内容参考，不再用于渲染网站。网站没有编造新增成果、团队成员或荣誉。
